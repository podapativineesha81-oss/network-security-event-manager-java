# Network Security Event Manager (Java)

A simple console-based **Network Security Event Manager** developed using Core Java and Object-Oriented Programming (OOP).

The application allows users to record and manage basic security events through a menu-driven interface.

## Features

- Add security events
- View all security events
- Search event by ID
- Update event information
- Delete security events
- Store event names
- Store event types
- Store source IP addresses
- Track severity levels
- Track event status
- Menu-driven interface
- ArrayList-based storage

## Technologies Used

- Java
- Object-Oriented Programming
- ArrayList
- Scanner
